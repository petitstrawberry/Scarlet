# 1.0 package inventory

Target: `1.0.0`. This inventory describes the coordinated release-preparation
branches. Version alignment establishes a baseline; it does not mean that every
crate provides a stable public API or that every hardware target is complete.

The four release repositories contain **55 Cargo packages**: 54 project-owned packages
and the vendored `sunset` package. Workspace-only manifests are not packages.
The package roles below distinguish release libraries, applications, board
integration, and development fixtures; roles do not themselves decide the
supported 1.0 API surface.

## Scope decisions

- Preserve vendored `sunset` at its upstream `0.4.0` version; it is sourced
  from `mkj/sunset`, not maintained as a first-party Scarlet release package.
- The [release scope](1.0-scope.md) selects all project-owned packages for
  coordinated version alignment, including examples, test fixtures, project
  BSPs, and helper tools. A Git
  repository tag includes these files even if the package is not distributed
  separately. Retain existing `publish = false` declarations.
- The Chromebook project is outside this version alignment. SGFX may consume
  its userspace backend/codegen at `0.1.0`; their package numbers do not need
  to match SGFX. Chromebook hardware completion is not a Scarlet release gate.
- Account for manifest dependency version constraints, Cargo lockfiles, project
  locks, and generated version metadata when finalizing the release.
  Do not change wire-version constants to match a package number.
- Final public dependency references, Nix pins, and project locks are fixed
  separately from package version alignment. Release branches are not immutable
  release tags.

## External Chromebook graphics dependencies

[scarlet-project-chromebook](https://github.com/petitstrawberry/scarlet-project-chromebook)
is a separate hardware project, not a member of the coordinated `1.0.0`
version alignment. Its userspace graphics packages remain at `0.1.0`:

| Package | Version | Role |
| --- | --- | --- |
| `sgfx-backend-scarlet-adreno` | `0.1.0` | SGFX userspace Adreno backend |
| `sgfx-codegen-adreno-a6xx` | `0.1.0` | Adreno shader code generation |

Select compatible published revisions through the consuming Cargo locks.
Shared SGFX Rust types must still resolve to a consistent source; matching
package version numbers across repositories is not required. No Chromebook
release branch, board release, or hardware completion is required for Scarlet
`v1.0.0`.
