# SCPM (Scarlet Package Manager) 設計方針書

## 概要

SCPMはScarlet OS用のシンプルなパッケージマネージャーです。tar.gz形式のアーカイブを解凍し、システムにインストール・アンインストール・検索・情報表示を行います。

## 設計方針

### 基本原則

1. **シンプルさの原則**: 実装の複雑さを避ける
   - 最小限の依存関係（tar-no-std, miniz_oxideのみ）
   - シンプルなアーカイブ形式（tar.gz + package.toml）
   - ユーザーフレンドリーなパス（`scarlet/`以下）

2. **既存環境との互換性**: Scarletのディレクトリ構造を尊重する
   - システムルート `/` 直下に展開
   - `/bin`、`/lib` などの既存パスを活用
   - 他のパッケージマネージャー（dpkg, apk, pacmanなど）との競合を避ける

3. **安全性**: 上書き防止と予期可能な挙動
   - 既存ファイルのチェック（上書き防止）
   - パッケージの依存関係確認

4. **スケーラビリティ**: 将来的な拡張性を考慮する
   - プラグイン形式（.deb）への対応可能性
   - データベース管理

### パッケージ構造

```
{package-name}-{version}.scarlet
├── package.toml          # メタデータ（アーカイブのルート）
├── bin/                  # バイナリ
│   ├── hello             # 実行ファイル
│   └── ...              # 他のバイナリ
├── lib/                  # 共有ライブラリ
│   ├── libexample.so     # 共有ライブラリ
│   └── ...              # 他のライブラリ
├── usr/share/            # データファイル（マニュ、ドキュメント）
│   ├── applications/      # アプリケーションメタデータ
│   ├── icons/           # アイコン
│   └── ...              # その他のファイル
└── etc/                  # 設定ファイル
    ├── config/             # システム設定
    └── other/              # その他の設定
```

### パッケージメタデータ (package.toml)

```toml
[package]
name = "hello"
version = "0.1.0"
description = "Hello world test package"
author = "Test"

[bin]
# メインバイナリ（または1つのみ）
name = "hello"
path = "bin/hello"

[[binaries]]
# 追加のバイナリ（マルチバイナリなど）
# name = "tool1"
# path = "bin/tool1"

[lib]
# 共有ライブラリ（オプション）
# path = "lib/libexample.so"

[[libraries]]
# 追加のライブラリ
# path = "lib/libexample2.so"

[files]
# インストールされるファイル
path = "etc/scpm/config.conf"
type = "config"

[[files]]
# データファイル
path = "usr/share/applications/hello.desktop"
type = "desktop"

[[files]]
# ドキュメント
path = "usr/share/doc/scpm/hello.README"
type = "doc"
```

### 配置パスの仕様

| カテゴリ | インストール先 | 説明 |
|----------|-----------------|----------|
| bin/ | `/bin` | 実行ファイル |
| lib/ | `/lib` | 共有ライブラリ |
| usr/share/ | `/usr/share` | マニュ、ドキュメント |
| etc/ | `/etc` | 設定ファイル |

### 依存関係

- **バイナリの依存**: 現在は共有ライブラリが最小限で済み
- **パッケージの依存**: 将来的な機能として実装
  - 他のパッケージへの依存（パッケージ間の依存）
  - ライブラリの共有（静的リンク）

### インストール時の処理

1. **パッケージの検証**:
   - 既存の同名パッケージの確認
   - バージョン互換性の確認
   - 依存関係の解決

2. **ファイルの展開**:
   - `bin/` → `/bin/`
   - `lib/` → `/lib/`
   - `usr/share/` → `/usr/share/`
   - `etc/` → `/etc/`

3. **アンインストール時の設定**:
   - 実行権限の設定（`mark_executable`）
   - シンボリンクの作成（必要に応じて）

4. **追跡情報の管理**:
   - `PackageMetadata.installed_files`フィールドで追跡
   - アンインストール時のデータベース更新
   - アンインストール時の`scpm list`で確認可能

### リスクと対策

| リスク | 説明 | 対策 |
|------|------|----------|
| 上書き防止 | 既存ファイルのチェック | リストアップデート（将来的） |
| バージョン競合 | 同名パッケージの管理 | バージョン情報の追跡 |
| 依存管理 | 未実装 | 手動管理、依存チェック |
| システム整合性 | 簡単な構造 | 既存パスの活用 |

### コマンド仕様

| コマンド | 説明 |
|----------|----------|
| `scpm list` | インストール済みパッケージの一覧 |
| `scpm info <pkg>` | パッケージの詳細情報 |
| `scpm install <package.scarlet>` | パッケージのインストール |
| `scpm remove <pkg>` | パッケージのアンインストール |
| `scpm search <query>` | パッケージの検索 |
| `scpm files <pkg>` | パッケージの追跡ファイル一覧 |

### 現在の実装状況

#### ✅ 実装済みの機能
- パッケージの解凍（tar-no-std + miniz_oxide）
- パッケージの抽出と展開（`extract_to`, `extract_root`）
- 基本的なコマンド実装
- 追跡ファイルの管理（`installed_files`）
- 上書き防止

#### 🚧 実装中/未実装の機能
- 依存関係の自動解決
- リモートリポジトリからのフェッチ
- 設定ファイルの管理
- アップデート機能
- プラグイン形式（.deb）への対応

### 将来的な拡張性（メモ）

1. **プラグイン形式対応**: パッケージマネージャーのプラグインインタフェース定義
2. **リモートリポジトリ**: `http://server/packages/index.toml` などからのパッケージインデックス
3. **データベース管理**: インストール情報をデータベースで永続化

### 結論

SCPMは「最小限のパッケージマネージャー」として設計されています。

- ✅ シンプル: 実装が進みやすく保守が容易
- ✅ 安全: 既存環境との親和性が高い
- ✅ 学習コスト: tar.gz形式は標準的で理解しやすい
- 🔄 スケーラブル: 将来的な拡張性を備えた設計

この設計方針に基づき、Scarlet OSで使いやすいパッケージマネージャーを目指します。
